- All devices within the laboratory are connected to a network switch that allows data communication between the various devices.
- Each device is treated as a static endpoint so that it is always easily accessible. At all times if a device, whether wired or wireless, is connected to the network it immediately has access to data from the other devices.

**HARDWARE**
- Core switch: Netgear XS508M, 10G, for the workstations and the Wi-Fi
- 10G switch: QNAP QSW-1208-8C, for the NAS, the render node and the LED processor
- Switch for the recorders, the audio console and external devices: Netgear JGS524
- OptiTrack cameras: Netgear GS724TPP and GS324PP PoE switches, daisy-chained
- Wi-Fi: ASUS TUF AX5400
